NetScaler RXSS PoC. POST /cgi/logout

This PoC sends a POST request to /cgi/logout with attacker-controlled RelayState. On affected instances, the response renders attacker-controlled content and triggers JavaScript execution.

Notes

  • The PoC uses a standard HTML form POST. Browsers cannot attach custom headers such as X-HackerOne-Research via a normal form submission. For header-tagged reproduction, please replay the same request in Burp (as included in the report).
  • If the instance responds with a 302 and HTML body, the payload is rendered in the response and triggers execution (alert).
